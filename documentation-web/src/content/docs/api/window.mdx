## Overview

Window and tab APIs are **client-only** and control MCM UI navigation. Calling them from a server-context script raises an error, so gate them behind `Ext.IsClient()` or keep them in client-only files.

## Methods

| Function | Description |
|---|---|
| `MCM.OpenMCMWindow()` | Open the MCM window |
| `MCM.CloseMCMWindow()` | Close the MCM window |
| `MCM.OpenModPage(tabName, modUUID?, shouldEmitEvent?)` | Open a specific mod page |
| `MCM.InsertModMenuTab(tabName, tabCallback, modUUID?, skipDisclaimer?)` | Add a custom tab; `tabCallback(tab)` builds its content. `skipDisclaimer` (default `false`) renders immediately without the disclaimer screen |

## Example

```lua
MCM.OpenMCMWindow()
MCM.OpenModPage('General', ModuleUUID)

-- Add a custom tab whose content you build with IMGUI
MCM.InsertModMenuTab('My tab', function(tab)
    tab:AddText('Built with custom IMGUI')
end)
```
